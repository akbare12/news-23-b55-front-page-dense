## How it works

`draw.py` (Pillow) renders `entry.png` (1024×1024, under 1 MiB). `main.py`
(stdlib only) copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`, verifying the PNG
header, dimensions, size and trailer first.

```sh
python3 draw.py
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
